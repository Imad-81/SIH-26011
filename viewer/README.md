# SIH26011 — Interactive 3D Urban Digital Twin Viewer

High-performance geospatial 3D digital twin web application built with **Next.js 16**, **React 19**, **Three.js**, and **React Three Fiber (R3F)**.

---

## ⚡ Performance Architecture

- **GPU Batched Mesh Rendering (`THREE.BatchedMesh`)**: Renders thousands of complex building geometries and skyscrapers in single-digit draw calls with 60+ FPS.
- **Dynamic Level-of-Detail & Spatial Sectors**: Buildings are partitioned spatially into sectors with smooth GPU color updates and zero-copy buffers.
- **Dynamic Terrain Conformity**: Real Copernicus DEM ground elevation grid with bilinear interpolation for buildings, water bodies, and roads.
- **Multi-Tier 3D Highway Network**: IRC:54 compliant elevations with Hermite ramp easing and concrete cylindrical support piers.

---

## 🎮 Features

- **5 Render Modes**:
  - **Height**: Continuous elevation color gradient with glowing skyscraper wireframes.
  - **Landuse / Typology**: Delineates commercial, IT park, residential, academic, and civic buildings.
  - **Data Quality**: Color-coded confidence tiers (Authoritative Registry, nDSM, OSM Tags, Cluster Propagation, Morphological).
  - **Flood Simulation**: Interactive floodwater elevation slider with building submersion risk indicators.
  - **Solar Potential**: Rooftop photovoltaic generation and carbon offset potential estimations.
- **Lighting & Atmosphere**:
  - Full Day/Night/Dusk/Dawn cycle with dynamic atmospheric scattering, stars, and directional sunlight.
  - Night mode with illuminated building windows and simulated vehicle traffic flow.
- **Navigation & Tours**:
  - Interactive smooth flight to any clicked building.
  - Cinematic drone camera tour traversing Durgam Cheruvu, HITEC City, Knowledge City, and Financial District.
  - Camera presets for rapid viewpoint switching.
- **Analytics Dashboard**:
  - Modal providing aggregate city metrics: total footprint area, built volume, gross floor area, and solar potential.

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run linter
npm run lint

# Build production bundle
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## 📁 Directory Structure

```
viewer/
├── public/
│   └── data/               # Synchronized datasets generated by scripts/pipeline.py
│       ├── buildings.json  # 3D building polygons & attributes

│   ├── app/                # Next.js 16 App Router (page.tsx, layout.tsx, globals.css)
│   ├── components/         # Three.js & UI components
│   │   ├── Scene.tsx       # R3F Canvas and scene graph
│   │   ├── Buildings.tsx   # BatchedMesh 3D building renderer
│   │   ├── Roads.tsx       # 3D roads, flyover bridges, and traffic particles
│   │   ├── Terrain.tsx     # DEM terrain mesh
│   │   ├── Water.tsx       # Water shader and reflection plane
│   │   ├── SunSky.tsx      # Atmospheric sun, sky, and directional lighting
```
